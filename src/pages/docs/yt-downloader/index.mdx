## <I18n keyName="docs.downloader.dev.title">개발 버전 실행</I18n>

```sh
git clone https://github.com/fabyday/yt-downloader.git
cd yt-downloader
pnpm install
pnpm dev
```

<p><I18n keyName="docs.downloader.requirements" html>Node.js 22 이상과 pnpm 10 이상이 필요합니다. 기본 바이너리는 <code>thirdparty/bin/&lt;platform&gt;</code>에서 불러옵니다.</I18n></p>
